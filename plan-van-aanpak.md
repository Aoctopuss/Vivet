## Wat is Vivet?

Vivet is een webshop voor casual streetwear. Bezoekers kunnen kleding bekijken, in hun winkelwagen stoppen en bestellen. Er is ook een adminpagina om producten en bestellingen te beheren.

---

## Functionaliteiten

**Klant:**
- Producten bekijken
- Producten toevoegen aan de winkelwagen
- Winkelwagen leegmaken
- Bestelling plaatsen en bevestiging ontvangen

**Admin:**
- Bestellingen bekijken
- Producten toevoegen, bewerken en verwijderen
- Producten resetten via de API

---

## Technieken

- HTML, CSS-tailwind, JavaScript
- JSON voor API 
- LocalStorage voor winkelwagen, producten en bestellingen
